VISION APARTMENTS — ЛОКАЛЬНЫЙ ИНТЕРАКТИВНЫЙ САЙТ

Эта папка содержит исходный код и все используемые ресурсы сайта.
Работа ведётся локально. Ничего не опубликовано, в Tilda ничего не загружено.

КАК ОТКРЫТЬ
На Mac дважды нажмите START.command. Откроется браузер с локальным сайтом.
Окно запуска нужно оставить открытым, пока используется сайт.
Для остановки нажмите Control+C в этом окне.
Открытие index.html напрямую не подходит для модулей и загрузки 3D-ресурсов.

СТРУКТУРА
Общее фото и название комплекса → интерьер → контакты и форма предпросмотра.
Большие рекламные заголовки и каталог других квартир удалены из этой версии.
Форма демонстрационная: данные никуда не отправляет.
Контакты (телефон, адрес, Instagram, локация) взяты из исходной сборки и
ТРЕБУЮТ СВЕРКИ с официальными данными застройщика перед публикацией.

УПРАВЛЕНИЕ
Основное перемещение на компьютере — клавиши W A S D (удерживайте для непрерывной
ходьбы с разгоном и торможением). A/D — шаг вбок, стрелки ←/→ — поворот, Esc — стоп.
Мышью потяните по сцене для осмотра (осмотр не запускает ходьбу).
У стен и мебели камера скользит вдоль препятствия (capsule + wall-slide).
Небольшая карта справа — для ориентации: названия комнат, площади, положение и
направление взгляда. Клик по комнате на карте не запускает автомаршрут.
Клик по полу не используется как основной способ ходьбы (R08, 2026-10-25).
Мобильный черновик (не финал, не «готово на телефоне»): полноэкран = вход в тур; удержание одного пальца — ходьба вперёд; второй палец — направление взгляда; Esc / выход из полноэкрана — выход из тура. Вне тура страница может прокручиваться. Нативный scroll посреди того же жеста тура не обещается.

ОСНОВА ПЛАНИРОВКИ
Использована предоставленная схема квартиры №296, подъезд 5, этаж 13.
Сумма внутренних зон в plan.js (13 зон без террасы) — 134,7 м²; терраса — 33,1 м².
Ранее в README стояло «143,7 м²» — эта цифра не совпадает с суммой зон plan.js
и требует сверки с исходной схемой (возможна опечатка 134,7↔143,7 или учёт стен).
До сверки опираемся на 134,7 м² по зонам плана.
Высота потолка 3,40 м подтверждена пользователем и задана в сцене.
На публичном сайте эта квартира записана как 176,8 м² (= 143,7 + 33,1); при 134,7 по
зонам сумма была бы 167,8 м². Расхождение требует сверки с официальными данными.
Комнаты, перегородки, дверные связи и терраса обведены по растровой схеме.
Проверка 169 пар направлений между 13 зонами прошла без пересечений
со стенами, открытыми дверями и заданными препятствиями мебели.
Проверка не заменяет обмеры, CAD-чертёж и визуальную проверку каждого прохода.

ИНТЕРЬЕР
Это предложенная дизайн-концепция по плану, а не съёмка существующего ремонта.
Обновлены пол, матовые ткани, мебель гостиной, встроенная ТВ-панель, свет,
скрытые рамы дверей, материалы кухни и санузлов. Стены помещений не переносились.
В гостиной старый большой обеденный стол заменён зоной отдыха; обеденная зона
сохраняется на кухне. Мебель и отделка не являются обещанной комплектацией.
Прямоугольный элемент на террасе сохранён без утверждения о его назначении.

ТОЧНОСТЬ И КАЧЕСТВО
Растровой схемы недостаточно для подтверждения всех размеров до сантиметра.
Для финальной геометрии нужны исходный чертёж или обмеры проёмов и стен.
Двери 2,75 м, подоконные части остекления и ограждение террасы — проектные
допущения прототипа; их нужно подтвердить отдельно.
Небо — нейтральный световой фон. Реальный вид с этажа не воссоздан.

Подключены фактуры 4096 px для дуба, камня и ткани. На узких экранах часть
из них заменяется версиями 1024 px. Разрешение самого кадра зависит от экрана
и плотности пикселей: наличие 4K-фактур не означает готовый фотореалистичный
кадр 3840×2160 на каждом устройстве. Это рабочая версия реального времени;
её детализация и освещение ещё могут отличаться от полноценного archviz-рендера.

assets/modern-interior-reference-v1.png — отдельно сгенерированный ориентир
по современной отделке и свету. Он не подменяет 3D-сцену и не является
подтверждением точной геометрии: генерация расширила проём и изменила часть
обстановки. В интерактивной модели используется геометрия исходной схемы.
Промпт и способ генерации сохранены в DESIGN_REFERENCE_PROMPT.txt.
