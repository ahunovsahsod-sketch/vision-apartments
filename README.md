# Vision Apartments

Interactive apartment walkthrough, apartment 296. Ceiling height: 3.40 m.

- Main experience: `index.html`
- Atelier experience: `atelier.html`
- Comparison: `comparison.html`
- Local preview: `python3 preview.py`

Desktop: WASD to move, mouse drag to look. Mobile: one finger scrolls; joystick plus a second finger enables walking and looking.

The repository is intended to remain private. Public hosting of the tour is authorized separately. No Tilda integration has been deployed.

See `README_RU.txt`, `ASSET-LICENSES.txt`, and `ASSETS_NEXT.txt` for technical details, third-party licenses, and current visual limitations. The contact form is a demo and does not submit applications.
